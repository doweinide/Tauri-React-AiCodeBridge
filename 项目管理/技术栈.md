| 层 | 技术 | 原因 |
|---|---|---|
| 桌面框架 | **Tauri 2** | 跨平台、体积小、本地能力强、安全边界清晰 |
| Frontend | **React + TypeScript** | 文件树、Diff、状态管理生态成熟 |
| UI | **Tailwind CSS + shadcn/ui** | MVP 开发速度快，桌面工具适合 |
| 状态管理 | **Zustand** | 简单，适合 Context / Project / ChangeSet 状态 |
| 文件树 | **react-arborist** 或自研虚拟 Tree | 支持大量文件 |
| Editor / Preview | **Monaco Editor** | Diff、代码高亮、编辑体验成熟 |
| Diff | **Monaco Diff Editor** + Rust 后端校验 | UI 展示成熟，核心逻辑不要只依赖前端 |
| Backend | **Rust** | 文件系统、Hash、Ignore、Apply、安全校验 |
| 文件扫描 | Rust `walkdir` | 高效递归扫描 |
| Ignore | Rust `ignore` crate | Gitignore 风格规则成熟 |
| Hash | SHA-256 / BLAKE3 | 外部修改检测 |
| 序列化 | JSON / Serde | Project / Context / ChangeSet |
| 本地持久化 | SQLite | Recent Projects、Settings、Change History |
| DB Layer | **rusqlite** 或 **SQLx** | MVP 推荐 rusqlite，简单直接 |
| 配置 | JSON/TOML + SQLite | 全局设置与项目设置分离 |
| Build | Tauri CLI | macOS / Windows / Linux |
| 测试 | Rust unit/integration + Vitest + Playwright | 核心引擎和 UI 分开测试 |
