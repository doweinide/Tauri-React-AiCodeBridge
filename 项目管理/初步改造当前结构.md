```text

```


# 5. App 入口结构

`main.tsx`：

```text
main.tsx
  ↓
app/App.tsx
  ↓
App Providers
  ↓
Application Shell
  ↓
Features
```

建议：

```tsx
main.tsx
```

只负责：

```text
createRoot
↓
render App
```

`app/App.tsx` 负责：

```text
ErrorBoundary
ThemeProvider
QueryClient
i18n
MainWindow
```

不要把业务初始化继续塞进 `main.tsx`。

# 7. Feature 内部规则

Feature 自己的东西尽量放一起。

例如：

```text
features/preferences/
├── panes/
├── shared/
├── PreferencesDialog.tsx
├── ShortcutPicker.tsx
├── preferences-store.ts
├── preferences-types.ts
└── index.ts
```

不要：

```text
components/preferences/
services/preferences/
store/preferences-store.ts
types/preferences-types.ts
```

把一个 Feature 拆散到四五个顶层目录。

# 15. Rust Command 规则

所有：

```text
#[tauri::command]
```

只负责：

```text
参数接收
权限/输入边界
调用 service
返回结果
```

不要写：

```rust
#[tauri::command]
fn xxx() {
    // 500 行业务逻辑
}
```

目标：

```text
Tauri Command
      ↓
Service
      ↓
Infrastructure / State
```



```text

```

而不是互相 import。
