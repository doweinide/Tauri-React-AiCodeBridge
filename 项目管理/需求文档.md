**产品代号：AI Context Tool**

**产品阶段：MVP**

---

# 一、产品概述

## 1.1 产品定位

本产品是一款独立桌面软件，用于连接开发者的本地代码项目与网页 AI。

产品不依赖特定 AI 服务，也不要求用户购买 AI Coding Agent。

用户可以：

1. 打开本地项目；
2. 选择与当前需求相关的目录和文件；
3. 自动生成精简的项目 Context；
4. 将 Context 复制到 ChatGPT、DeepSeek、Gemini 等网页 AI；
5. 要求 AI 按指定格式返回项目修改结果；
6. 将 AI 返回结果复制回软件；
7. 自动解析新增、修改、删除的文件；
8. 查看 Diff；
9. 确认后应用修改到本地项目；
10. 支持撤销修改。

---

# 二、产品目标

## 2.1 核心目标

解决使用免费网页 AI 编程时的两个核心问题：

### 问题 1：Token 浪费

开发者不需要把整个项目发送给 AI，只需要发送当前任务相关的最小 Context。

### 问题 2：AI 代码无法直接落地

AI 返回代码后，开发者不需要手动寻找文件、复制代码、创建文件和删除文件。

软件负责：

**解析 → Diff → Apply。**

# 三、目标用户

## 3.1 主要用户

### 用户 A：免费 AI 用户

使用：

- ChatGPT 免费版
- DeepSeek
- Gemini
- 其他免费网页 AI

不希望购买 Cursor、Claude Code 等 AI Coding 工具。

### 用户 B：低成本 AI 用户

拥有 AI 会员，但希望减少 Token 使用量，提高上下文利用率。

### 用户 C：大型项目开发者

项目包含大量文件，只希望把与当前任务相关的代码交给 AI。

# 四、核心用户场景

## 场景 1：修改一个小功能

用户需求：

```text

│   ├── session.ts
│   └── token.ts
├── components/
├── services/
└── pages/
```

```text

```

```text

+

+

```

AI 修改完成后，用户复制 AI 返回内容。

软件自动：

```text
识别 login.ts
↓
生成 Diff
↓
用户确认
↓
Apply
```

```text

+
```

> Preview 中看到的内容 = Copy 后发送给 AI 的内容。

```text
Project: ~100,000 tokens
Context: ~5,600 tokens

Reduction: 94.4%
```

Token 为估算值，应明确标记为 Estimated。

# 6.7 Change Parser

## FR-PARSER-001 解析 ADD

AI 返回：

```text
ADD
src/auth/oauth.ts
```

软件创建一个待添加文件。

---

## FR-PARSER-002 解析 MODIFY

AI 返回：

```text
MODIFY
src/auth/login.ts
```

软件读取 AI 返回内容，与本地文件进行 Diff。

---

## FR-PARSER-003 解析 DELETE

AI 返回：

```text
DELETE
src/auth/old.ts
```

软件标记文件删除。

---

## FR-PARSER-004 非标准响应

如果 AI 没有按照格式返回：

```text
Unable to parse response.

Please ask AI to return changes using the required format.
```

不能直接修改本地文件。

# 6.9 Apply Engine

## FR-APPLY-001 修改文件

将确认后的内容写入本地文件。

---

## FR-APPLY-002 创建文件

AI ADD 文件时创建目录和文件。

---

## FR-APPLY-003 删除文件

AI DELETE 文件时删除文件。

删除前必须经过用户确认。

---

## FR-APPLY-004 外部修改检测

如果：

```text
Context 创建时：

login.ts = Version A
```

之后用户在 IDE 修改：

```text
login.ts = Version B
```

AI 返回修改时，软件必须检测到：

```text
Local file has changed since Context was created.
```

禁止静默覆盖。

用户需要：

```text
[Review Again]
[Overwrite]
[Cancel]
```

---

## FR-APPLY-005 Undo

Apply 后提供：

```text
Undo
```

至少支持撤销最近一次 Change Set。

# 九、安全需求

这是 P0/P1 级别功能。

## 9.1 不允许 AI Response 任意写入系统

所有路径必须限制在项目根目录内。

禁止：

```text
../../
```

以及绝对路径。

---

## 9.2 默认保护敏感文件

敏感文件默认不进入 Context。

---

## 9.3 Apply 前必须 Diff

原则：

> AI 返回内容不能直接覆盖本地文件。

流程必须：

```text
AI Response
↓
Parse
↓
Diff
↓
User Confirm
↓
Apply
```

# 十九、最终产品定义

### 产品是什么？

**一个独立的本地 AI 编程上下文管理工具。**

### 它解决什么？

**减少 AI Token 浪费，并解决网页 AI 与本地项目之间的代码传递问题。**

### 用户怎么使用？

**选择 → 复制 → AI → 粘贴 → Diff → 应用。**

### AI 在哪里？

第一阶段：

**AI 不在软件里。**

用户可以继续使用自己习惯的免费 AI 网站。

### 软件最重要的技术能力是什么？

```text
Context Engine
+
Project Model
+
Change Parser
+
Diff Engine
+
Apply Engine
```

### 产品最重要的价值是什么？

> **让用户不用购买 AI Coding Agent，也能够用免费的网页 AI，以尽可能少的 Token 完成实际项目中的小型代码修改。**
